Interpretation

Why the result lands here.

The result is best read as a balanced benchmark entry: one overall score plus the lane measurements that produced it. Hard Intelligence score is 95.82 and contributes to the overall score alongside Full/Agentic and SWE. Runs on the Claude Max subscription; the transport is the official Claude Code CLI rather than a metered API key, so the subscription bills no marginal per-token charge. Reasoning effort is extra-high on every lane, matching the published extra-high baselines. Costed at the model’s published Standard API rates ($10.00/1M input, $50.00/1M output, $0.25/1M cache reads, $20.00/1M cache writes at the one-hour duration) as a comparable basis, not an invoice. The prompt prefix is cached by the subscription route, so pricing only the uncached remainder would understate each call. Thinking tokens are spent and billed on this route but are not returned as text, so reasoning content is absent while its token cost is counted. Hard Intelligence is a public diagnostic, not a hidden official score. Token median and P90 per scored item are intentionally omitted: their derivation could not be reproduced on the same basis as the published rows. Agentic prompts re-measured with a real tool loop. The earlier records were single-turn refusals that scored zero on capability while reporting the speed of the refusal as performance and efficiency; both are now measured from a real loop, so capability rises and the latency and cost terms fall. Net position on this table is unchanged.
